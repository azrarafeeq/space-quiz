# Orbit

Orbit is a small, dependency-free space exploration quiz. Answer ten questions, learn from the explanations, and review missed answers after the results screen.

## Run locally

No installation, build step, or server is required. Open `index.html` in a modern web browser.

## Deployment

The site is published with GitHub Pages. The GitHub Actions workflow stages `index.html` and deploys it whenever changes are pushed to `main`. The same workflow can also be started manually from the Actions tab.
